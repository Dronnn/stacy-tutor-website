# Сайт-визитка репетитора по математике и информатике

Лендинг для Анастасии Викторовны Майер — репетитора по математике и информатике, 1–11 класс.

## Технологии

- Чистый HTML / CSS / JS — без фреймворков
- Google Fonts (Inter)
- FormSubmit.co для отправки заявок на email
- Google Sheets + Google Apps Script для системы отзывов

## Возможности

- 18+ секций с полным контентом
- Тёмная / светлая тема (автоопределение + переключатель)
- 10 акцентных цветов на выбор (выпадающий пикер при наведении)
- Анимации при скролле (Intersection Observer)
- Параллакс-фоны на секциях
- Динамические отзывы из Google Sheets (форма отправки + модерация + карусель)
- FAQ-аккордеон
- Аккордеон программ обучения
- Адаптивная вёрстка (десктоп, планшет, мобильный)
- Форма заявки → email через FormSubmit.co
- Резюме преподавателя: PDF + онлайн-версия (одностраничная, A4, оптимизирована для печати)

## Структура

```
index.html              — основная страница
resume-1page.html       — онлайн-резюме (1 страница A4, для печати в PDF)
teacher.png             — фото преподавателя
резюме_*.pdf            — резюме в формате PDF
images/                 — фоновые изображения секций
docs/                   — требования, контент, идеи, Apps Script код
docs/google-apps-script.js — код API отзывов (для Google Apps Script)
archive/                — архивные варианты дизайна (warm, bold, zen)
wrangler.jsonc          — конфигурация Cloudflare Pages
```

## Деплой

Статический сайт — можно развернуть на Cloudflare Pages, GitHub Pages, Netlify или любом хостинге. Достаточно загрузить корневую папку.

Для Cloudflare Pages: `npx wrangler pages deploy ./`
