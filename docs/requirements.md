# Требования к сайту-визитке репетитора по математике

## Тип сайта

Одностраничный лендинг (10-14 блоков), вертикальная прокрутка. Главная задача — за 5 секунд дать ответ "кто, кому, зачем" и привести к записи на пробный урок.

---

## Структура блоков (в порядке приоритета)

### 1. Hero (первый экран) — ОБЯЗАТЕЛЕН

- Заголовок: "Репетитор по математике, X-Y класс"
- 1 фраза-обещание результата (закрыть пробелы / поднять оценки / подготовить к ВПР-ОГЭ)
- CTA-кнопка: "Записаться на пробный урок"
- Фото преподавателя

### 2. Кому подойдёт — ОБЯЗАТЕЛЕН

3-4 карточки-сегмента:

- Начальная школа (счёт, задачи, внимательность)
- 5-7 класс (база, дроби, уравнения)
- 8-9 класс (ОГЭ, геометрия, задачи второй части)
- "Боится математики" / "слабая база" / "нужно подтянуть оценки"

### 3. Результаты в цифрах — ОБЯЗАТЕЛЕН

- Количество учеников
- Лет опыта
- Средний рост оценки
- Количество сдавших ОГЭ

> Только реальные цифры, никакой "магии".

### 4. О преподавателе — ОБЯЗАТЕЛЕН

- Образование
- Опыт работы (школа / частная практика)
- Специализация (классы, экзамены)
- 1-2 фразы "как объясняю"

### 5. Как проходят занятия — ОБЯЗАТЕЛЕН

Формат "3 шага":

1. Знакомство + диагностика уровня
2. Индивидуальный план занятий
3. Домашка, разбор ошибок, контроль прогресса

### 6. Формат и инструменты — ОБЯЗАТЕЛЕН

- Онлайн / очно (указать конкретно)
- Платформа (Zoom / Google Meet)
- Инструменты (онлайн-доска)
- Длительность урока (45 / 60 / 90 мин)

### 7. Цены — ОБЯЗАТЕЛЕН

- Цена за урок + длительность
- Способ оплаты (за урок / пакет / помесячно)
- Что входит (проверка ДЗ, материалы, отчёт родителям)

### 8. Отзывы — ОБЯЗАТЕЛЕН

6-12 коротких отзывов. Каждый содержит:

- Кто (класс ученика)
- Цель (оценки / ОГЭ / понимание)
- Результат

### 9. FAQ — РЕКОМЕНДУЕТСЯ

Минимальный набор вопросов:

- С какого уровня можно начать?
- Сколько занятий нужно для результата?
- Что если пропустили урок?
- Будет ли домашка?
- Какой нужен компьютер / интернет?

### 10. Форма записи + финальный CTA — ОБЯЗАТЕЛЕН

Поля формы:

- Имя родителя
- Класс ребёнка
- Цель (подтянуть / ВПР / ОГЭ)
- Контакт (Telegram / телефон)
- Галочка согласия на обработку персональных данных

### 11. Контакты — ОБЯЗАТЕЛЕН

- Телефон
- Email
- Мессенджеры (Telegram / WhatsApp)
- Соцсети (если ведутся)

## Опциональные блоки (добавляют экспертность)

### Методика

- Диагностика на старте
- Индивидуальная программа
- Регулярные мини-тесты
- Разбор ошибок, не зубрёжка

### Виды занятий

- Индивидуально
- Мини-группа
- Тематический мини-курс (8 занятий на одну тему)

### Расписание

- Рабочие дни / часы
- Как выбрать время

### Материалы / Полезное

- Бесплатные тренажёры
- Чеклисты по темам
- "5 задач недели"

---

## Что НЕ нужно

- Не копировать формат агрегаторов (Profi.ru, Tutoronline) — это витрина, а не личный бренд
- Не врать в цифрах — сайт должен вызывать доверие, а не выглядеть как реклама
- Не перегружать текстом — родители решают за 5 секунд

---

## Ключевые принципы

1. **Быстрый ответ** — посетитель за 5 секунд понимает: кто вы, кому помогаете, какой результат
2. **Доверие** — реальные цифры, реальные отзывы, реальное фото
3. **Простота** — 3 шага, короткие тексты, понятная цена
4. **Один CTA** — всё ведёт к записи на пробный урок
